Known environment limitation (NOT a defect in this app)
-------------------------------------------------------
A pixel screenshot of the clone display could not be captured here:
  * altaris_screenshot      -> "No display frame"
  * altaris_record_start    -> starts, produces no file
  * rea.capture_adb_screen  -> rea.list_adb_devices returns devices: []
The same "No display frame" is returned for an unrelated ordinary app
(idm.internet.download.manager) on the same virtual display, so the display
capture path is unavailable in this container rather than our swapchain
failing. Frame delivery is therefore evidenced by the logcat counters above.
